# 得出合理结论

## R — 原文 (Reading)

> 重大的问题很少能用简单的"是"或绝对的"不是"来回答……二分式思维假设一个可能存在多种答案的问题只有两个可能的答案……灰度思维致力于探索用"是"和"不是"之外的其他方式回答复杂问题。
>
> — 尼尔·布朗、斯图尔特·基利《学会提问》第12章

> 避免二分式思维，你可以用"什么时候""什么地方""为什么或为了什么目的"等问题来为结论添加限制性的语境……使用条件句让我们能得出某个结论，而不用假装自己比实际知道得更多。
>
> — 同上，第12章

---

## I — 方法论骨架 (Interpretation)

面对同一套理由，很少只能推出一个结论。**二分式思维**（误以为只有两种对立结论，常与虚假两难同源）会过度限制视野；**灰度思维**承认多面、多可能结论，用"这取决于……"作答。

操作：当一套理由似乎指向唯一结论时，追问"还有哪些结论与这些理由同样契合"。再用三问为结论添加限定：①结论在"什么时候"准确？②在"什么地方"准确？③为"什么目的/为什么"准确？用"If…那么…"条件句表达受限结论，从而远离非黑即白。条件句体现批判性思维者的谦卑——承认所知不足以给确定答案，再从系列可选结论中挑最契合理由与自身价值偏好的那个。

## A1 — 应用示例 (Application Example)

### 示例 1：从理由生成多结论（原书例题改编）
- **类型与来源**：worked_example（第12章示范）
- **问题/输入**：理由"某国核能发电占比高且事故少"——有人据此得出"应全面推广核能"
- **方法论的使用**：灰度思维——这理由同样契合多个结论：①在能源短缺且地质稳定地区可推广；②在地震带或缺乏监管处应暂缓；③作为能源组合之一而非唯一。用三问限定："在什么时候准确"（地质稳定时）、"什么地方"（监管完善国）、"为何"（减碳目的）。得到条件句结论而非绝对"全面推广"。
- **结论**：多合理结论=[条件化推广/暂缓/组合之一]
- **结果**：原书以此说明二分式思维妨碍考虑多种可能

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要 this skill?

1. 面对"支持/反对"两极对立的争议，想避免非黑即白
2. 自己得出"绝对是/绝对不是"的结论，想检验是否过度简化
3. 写东西想给出有分寸、有条件的结论

### 语言信号 (用户的话里出现这些就应激活)

- "这件事是不是只有两种可能 / 非黑即白"
- "怎么得出更有分寸的结论"
- "gray area / 二分式思维 / 灰度思维"

### 与相邻 skill 的区分

- 与 `omitted-info` 区别：本卡在信息补全后"开放结论"；`omitted-info` 在之前"找缺失信息"。
- 与 `issue-conclusion` 区别：本卡是论证解剖的**收尾**（多结论）；前者是**起点**（找结论）。

## E — 可执行步骤 (Execution)

**必需输入**：一套已认可的理由（经过前序各卡评价）。
**交付物与完成标准**：输出"多个带条件的合理结论 + 自选立场"。

1. **查二分式**：是否误以为只有两种对立结论？→ 提醒自己多面可能。
2. **问多结论**：还有哪些结论与这些理由同样契合？
3. **三问限定**：结论在"何时"准确？"何地"准确？为"何目的"准确？
4. **条件句表达**：用"If…那么…"写出受限结论，承认所知不足。
5. **自选**：从可选结论中挑最契合理由与自身价值偏好的那个。

## B — 边界 (Boundary) ★

### 不要在以下情况使用 this skill（反场景）

- 事实性/数学性二值问题（"这是否为偶数"）确实只有两种答案，不必强行灰度。
- 紧急情况下需快速决断时，过度开放结论可能延误行动。

### 作者在书中警告的失败模式

- 二分式思维：误以为复杂问题只有两种答案，常与虚假两难谬误同源。

### 作者的盲点 / 时代局限

- 无。

### 容易混淆的邻近方法论

- "灰度思维"≠"和稀泥"：是给出有分寸的多结论，而非放弃判断。
