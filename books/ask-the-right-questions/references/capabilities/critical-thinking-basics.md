# 批判性思维基础心态

## R — 原文 (Reading)

> 批判性思维这一术语，指由以下三个维度激活的评估技能：①意识到一整套环环相扣的批判性问题；②有能力在适当时机以适当方式提出并回答这些问题；③有积极主动地使用这些批判性问题的强烈渴望。

> 弱势批判性思维是利用批判性思维来捍卫自己当前的信念。强势批判性思维是利用批判性思维来评价所有的断言和信念，尤其是对自己的信念加以评价。

## I — 方法论骨架 (Interpretation)

批判性思维不是"挑刺"，而是**一套可被激活的提问程序**，由三个维度同时具备才算真正掌握：①知识层——知道那套批判性问题清单；②技能层——会在恰当时机提出并回答；③意愿层——有主动使用的强烈渴望。

面对任何被说服的场景，先判断自己用的是哪种信息接收模式：**海绵式**被动吸收（无法判断该信什么）还是**淘金式**主动与材料辩论（边听边问）。使用批判性思维又有两种取向：**弱势**——只用来捍卫既有立场（目的=赢）；**强势**——用来评价一切断言，包括自己的（目的=逼近真理）。

批判性思维者赖以为凭的四种价值观是：自主决断（从最多可能性中选，故须听不同视角）、好奇心（不断提问）、谦恭有礼（承认自己认知有限）、尊重严密论证（对所有观点择优汰劣）。全书二字箴言是"放慢"——用系统 2（慢思考）去否决系统 1（快思考）的仓促决断。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面对他人兜售的观点/文章/广告/社媒言论，犹豫"该不该信、该信多少"
2. 发现自己或他人只在"捍卫既定立场"，而非公平评估
3. 在重大决策（消费、医疗、职业、投票）前，想先让大脑慢下来

### 语言信号 (用户的话里出现这些就应激活)

- "这篇说得好像很有道理，但我该信吗"
- "怎么判断专家/网红/文章说的靠不靠谱"
- "我总觉得他说得对，但说不出为什么"
- "critical thinking / 批判性思维 / 怎么独立思考"

### 与相邻 skill 的区分

- 与 `issue-conclusion` 区别：本卡是**元层心态与总入口**，解决"要不要信、用哪种思维"；`issue-conclusion` 等是后续**解剖论证的具体步骤**。先激活本卡，再按需要加载后续卡。
- 与 `obstacles` 区别：本卡讲"该用什么姿态"，`obstacles` 讲"执行时会撞上哪些内部减速带"。

## E — 可执行步骤 (Execution)

**必需输入**：一段待评估的说服性内容（文章/发言/广告），或"我要做某个决定"的情境。
**交付物与完成标准**：完成一次"三维度 + 思维模式 + 强弱取向 + 四价值观 + 放慢"的自检，明确"我先不急着信/做，先提问"。

1. **判定思维模型**：我现在是海绵式（照单全收）还是淘金式（主动提问）？→ 完成标准：能说出"我在和材料辩论什么"。
2. **判定强弱取向**：我用批判性思维是捍卫旧信念（弱势）还是评价一切包括自己（强势）？→ 完成标准：愿意先把同一套问题用在自己身上。
3. **四价值观自检**：我是否在听不同视角（自主决断）？在提问（好奇心）？在承认自己有限（谦恭）？在按论证质量而非身份取舍（尊重严密论证）？
4. **喊停切系统 2**：重大决策先"放慢"，自问"我到底依赖什么来支持我的信念和结论"。
5. **进入解剖**：带着淘金式姿态，依次加载 `issue-conclusion` 等后续批判性问题卡。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill（反场景）

- 紧急医疗/灾难/战场等**时间紧迫、信息不全**的情境：此时"相信专家/直觉/权威指令"可能比慢思考更优，本卡"放慢"原则须让位于生存需求（原书未给明确判据，列为时代/情境局限）。
- 对方**根本不认同批判性思维价值观**时：强行提问会终结对话，应先切 `expression-dialogue` 的对话策略维系关系。

### 作者在书中警告的失败模式

- 海绵式思维的致命缺陷：吸收越多越容易"读到什么信什么"，无判断方法。
- 弱势批判性思维：把"驳倒异见"当目标，毁掉批判性思维的人道与进步性。
- 一厢情愿（相信内心而非真相）：只信希望为真的，强令事实迎合信念（第13章，最大障碍）。
- 操控型论证：结论先行、理由后编，理由只是装饰预定结论（第1、3章）。

### 作者的盲点 / 时代局限

- 案例偏美国语境（医保、控枪、大麻），需自行迁移到本土场景。
- 对算法信息茧房、深度伪造、AI 生成内容等数字时代新型说服机制着墨有限。

### 容易混淆的邻近方法论

- "批判"≠"否定/抬杠"：本书强调评价+建构、含社交属性。
