## 1. 结构 (Structural)

### 类型

实操型思维训练手册。作者明言读者对象是普通大众而非专业人士，目标是传授一套"可广泛应用于各个领域"的提问技能。全书以**一组环环相扣的批判性问题（critical questions）**为骨架组织，每章聚焦一个问题的识别与解答程序。

### 一句话主旨

> 在信息泛滥、专家不可尽信的世界里，靠一套系统性的批判性问题（先找论题结论、再查理由、抠歧义、挖假设、查谬误、验证据、找替代原因、拆数据、补省略信息、开放结论），主动淘金式地评估他人论证，从而不盲从、做出自己的理性决断。

### 骨架 (主要论点及其关系)

1. **第 1 章 基础心态**：区分海绵式/淘金式思维、弱势/强势批判性思维，确立批判性思维者的四种价值观（自主决断、好奇心、谦恭有礼、尊重严密论证）；批判性思维是社交活动，需注意对话与表达策略。
2. **第 2–12 章 11 个批判性问题（论证解剖程序）**：依次拆解一个论证的构成要素——
   - 第 2 章 论题与结论（找到论证的"大厦柱石"）
   - 第 3 章 理由（第三块柱石）
   - 第 4 章 歧义/模棱两可的词
   - 第 5 章 价值观假设与描述性假设
   - 第 6 章 论证谬误
   - 第 7 章 证据效力（个人经历/典型案例/当事人证言/专家陈述）
   - 第 8 章 证据效力（个人观察/调查研究）
   - 第 9 章 替代原因
   - 第 10 章 欺骗性数据
   - 第 11 章 被省略的重要信息
   - 第 12 章 合理结论（二分式 vs 灰度思维）
3. **第 13 章 障碍**：识别干扰批判性思维的"减速带"——正确提问令人不快、快思考（系统 1）、刻板印象、背叛我们的思维习惯（晕轮效应、信念固着、可得性启发法、近因效应、答非所问、自我中心、知识的诅咒、一厢情愿/奇迹式思维）。

**论点之间的关系**：递进 + 并列。第 1 章是元层（心态与价值观），第 2–12 章是论证解剖的并列步骤（按"先找结构→再验质量→再开放结论"的逻辑递进），第 13 章是元层（执行障碍）。第 2、3、7、8 章反复出现"像批判性思维者那样写作和发言"小节，是贯穿全书的跨章表达框架。

### 作者要解决的核心问题

"该问哪些问题、如何提问，才能系统地对他人阐述的内容进行深思熟虑和公平允正的评价？"——即把"批判性思维"从口号变成一套可操作的提问清单。

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 批判性思维 | 由三维度激活的评估技能：①意识到一整套环环相扣的批判性问题；②能在适当时机以适当方式提出并回答；③有主动使用的强烈渴望 | 常识常把"批判性"等同于"挑刺/否定"，作者强调它是**评价+建构**、含社交属性 |
| 海绵式思维 | 像海绵吸水一样被动吸收信息，重获取结果 | 不等于"好好学习"；其致命缺陷是无法判断该信什么 |
| 淘金式思维 | 带着不断提问、与材料互动的态度阅读/倾听，主动掂量价值 | 常识以为"阅读=接受"，作者视阅读为对话/辩论 |
| 弱势 / 强势批判性思维 | 弱势=用批判性思维**捍卫**既有信念；强势=用批判性思维**评价所有**断言，包括自己的 | 常识把"会反驳别人"当成批判性思维强，作者认为那是弱势 |
| 论题 (issue) | 引起对话或讨论的问题/争议，是后续讨论的原动力；分描述型（世界**是什么**）与规定性（世界**该是什么**） | 常识不区分"事实之争"与"价值之争"，作者强调两类问题的评价类型不同 |
| 结论 / 理由 | 结论=作者的立场；理由=支撑结论的陈述；二者结合即"论证" | 常识常把"我觉得"当结论，作者要求区分结论与例子/数据 |
| 歧义 | 一个词/短语在同一语境中可能有多种合理解释，且影响结论 | 常识以为"我看懂了"就无歧义，作者要求主动找关键词的多义性 |
| 价值观假设 | 立论者认为"理当如此"的、未明言的抽象观念，连接理由与结论 | 常识常把价值观冲突当成"人品问题"，作者视其为可定位的隐藏前提 |
| 描述性假设 | 立论者以为理所当然的、关于世界**如何运转**的信念 | 同上，区别在于关乎"事实机制"而非"价值偏好" |
| 谬误 | 论证中的**欺骗手段**，交流者用它说服你接受结论 | 常识常记不住谬误名称；作者强调"会问问题就能识别，名字不重要" |
| 替代原因 | 对同一个结果，可能还有别的合理解释 | 常识易把"相关/先后"当成唯一因果 |
| 二分式思维 / 灰度思维 | 二分式=误以为只有两种对立结论；灰度=承认多面、多可能结论 | 常识默认"非黑即白"，作者提倡条件化、多结论 |
| 快思考 / 慢思考（系统 1 / 系统 2） | 系统 1=凭手边信息仓促决断；系统 2=慢速、有条理地理性评估 | 借用卡尼曼；作者视"慢"为全书二字箴言 |
| 确认偏误 / 信念固着 | 只把能确认既有信念的证据当可靠证据；死守初始信念 | 常识以为"我客观"，作者指出人人都以为只有自己不偏 |

### 核心命题 (用自己的话)

1. 我们活在一个说服者真假参半、专家也常出错的世界，**不能**把思考外包给专家——必须自己做能工巧匠，剪裁取舍。
2. 批判性思维不是否定，而是**一整套可被激活的提问程序**；目标是从中得出自己可信的结论。
3. 评价一个论证前，必须先**定位它的结构**（论题、结论、理由），否则回应会驴唇不对马嘴。
4. 语言的歧义、隐藏的假设、论证中的谬误，是立论者"无意识或有意"留下的漏洞，都要靠提问挖出。
5. 证据有强弱之分（个人经历/案例/证言最弱，控制良好的研究最强），**相信直觉式证据是最大陷阱之一**。
6. 看到因果/数据结论时，要主动找**替代原因**、查**数据欺骗**、问**被省略的信息**，再考虑**多个合理结论**。
7. 即便学会方法，人仍会被思维习惯（快思考、偏见、一厢情愿）拖回原地——这些"减速带"要被持续警惕。

### 论证链

作者的论证路径：世界嘈杂→专家不可尽信（第 1 章前提）→因此需要一套提问工具→按"结构（2–4 章）→隐藏前提（5 章）→推理质量（6–8 章）→因果与数据（9–10 章）→信息完整（11 章）→结论开放（12 章）"的顺序解剖一个论证→最后（13 章）提醒执行这套工具时人会遇到的内部障碍。证据多来自日常说服场景（广告、政治辩论、新闻、研究报道）的例题与"自问自答"式示范。

## 3. 批判 (Critical) ★

### 作者的时代局限

- 本书初版于 1978 年，第 12 版（2021）虽吸收了卡尼曼"快/慢思考"等进展，但案例偏美国语境（医保、控枪、大麻合法化等），中文读者需自行迁移到本土场景。
- 对"社交媒体算法投喂""深度伪造/AI 生成内容""信息茧房"等数字时代新型说服机制着墨有限，书中"找替代来源"的建议在算法过滤气泡下执行成本更高。

### 作者的立场盲点

- 作者站在**自由派通识教育**立场，默认"多元视角、开放讨论"是好事；但对"某些情境下（如紧急情况、权威指令）快速服从比慢思考更优"这类反例讨论不足。
- 全书聚焦"评价他人论证"，对"如何**提出**有建设性的好问题（而非只是挑错）"和"在权力严重不对等时如何安全地提问"着墨较少（仅第 1 章简单给了 8 条对话策略）。

### 未被证明的假设

- 假设"只要个人掌握提问技能，社会就能高效运转"——这是渐进改良式乐观，未论证制度/结构因素如何被个人批判力改变。
- 假设"严密论证值得尊重"是普世价值观，但在某些文化中"面子/关系"可能压过"论证质量"，作者未充分处理跨文化冲突。

### 最强反对意见

- 若有人反驳：在紧急医疗、战场、灾难等**时间紧迫、信息不全**的情境，系统 2 慢思考可能致命，此时"相信专家/直觉"才是理性选择——作者对此类"慢思考的适用边界"未给出明确的情境化判据。

> **以上批判会直接成为下游 skill 的 Boundary (B) 字段来源**

## 4. 应用潜力 (Applicability)

### 可 skill 化的内容

- [ ] **批判性思维基础**（海绵式 vs 淘金式；弱势 vs 强势；四种价值观；何时放慢）
- [ ] **识别论题与结论**（区分描述型/规定性论题；5 条找结论线索）
- [ ] **识别理由**（理由与结论的绑定；让理由结论一目了然）
- [ ] **识别歧义**（找准关键词；判定歧义是否影响结论）
- [ ] **识别假设**（价值观假设：从背景/后果找；描述性假设：从"不证自明"处找）
- [ ] **识别论证谬误**（14 类常见谬误 + "问对问题就能识别"的检测策略）
- [ ] **评估证据效力**（个人经历/案例/证言/专家/观察/调查研究各自的可靠性判据）
- [ ] **寻找替代原因**（相关≠因果；在此之后≠因此；唯一原因还是之一）
- [ ] **识破欺骗性数据**（不知来历的数据、迷惑的平均值、测量误差、省略信息）
- [ ] **发现被省略的信息**（提问清单；负面视角的重要性）
- [ ] **得出合理结论**（二分式→灰度；条件化结论）
- [ ] **批判性思维障碍自检**（快思考/偏见/一厢情愿等"减速带"及识别法）
- [ ] **像批判性思维者那样对话与表达**（语气策略、不过度依赖专家、让对话延续）

### 不适合 skill 化的内容

- 各章末尾的"思维体操"练习题与参考答案（作为 example 素材，不独立成 skill）
- 赞誉、前言、译后记（背景叙事）
- 具体名人/事件案例本身（作为 case 素材保留，不独立成 skill）

### 预估 skill 数量

**约 11–13 个能力单元**（11 个批判性问题 + 基础元层 + 障碍层；表达/对话框架可与基础合并或独立）。阶段 1.5 决定保留数量，阶段 1.6 与输出模式决定独立入口数量，不硬凑。
