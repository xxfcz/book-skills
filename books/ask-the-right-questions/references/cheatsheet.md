# 决策规则速查 — 《学会提问》（原书第12版）

| 能力 | 一句话规则 |
|---|---|
| 批判性思维基础心态 | 先用三维度+淘金式+强势+慢思考自检"该不该信、用哪种思维"，再进入解剖 |
| 识别论题与结论 | 先判描述型/规定性论题，再用5线索定位结论，排除例证数据等干扰 |
| 识别理由 | 对结论问"为什么"，用指示词定位理由，列表并与结论绑定 |
| 识别歧义 | 盯关键连接词与抽象词，用双义检验判定是否影响结论，责任归说服者 |
| 识别假设 | 在理由结论间找连接假设，并定位价值观假设与描述性假设 |
| 识别论证谬误 | 整理结构后查错误假设与欺骗形式，识别14类常见谬误 |
| 评估证据效力 | 按来源梯度与10问评估证据，研究只能支持不能证明结论 |
| 寻找替代原因 | 对因果断言用4解释检验，查事后归因与唯一/之一 |
| 识破欺骗性数据 | 追数据来源、辨平均值类型、防张冠李戴、问缺失信息 |
| 发现省略信息 | 按9类线索找被省略的信息，强化负面视角 |
| 得出合理结论 | 用二分式→灰度，以何时/何地/为何三问生成条件化多结论 |
| 批判性思维障碍自检 | 自检12类思维减速带，遇重大决策喊停切系统2慢思考 |
| 像批判性思维者那样表达与对话 | 用恰当语气、不堆砌专家，并以8策略让对话延续 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
