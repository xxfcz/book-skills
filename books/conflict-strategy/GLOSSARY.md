# 术语词典 — 《冲突的战略》

> 作者本人的用法，及其与常识用法的差异。对应各能力卡中的术语。

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 可信承诺 / 自我约束 (credible / self-commitment) | 一方以可信且可观察的方式**限制自己的选择自由**，改变对方预期、增强自身地位 | 常识认为"更多选择=更有利"；作者反其道：砍掉退路才更可信 |
| 谈判实力 (bargaining power) | 不是实力强就占优，而是**能自我约束、可信地放弃选择权**的一方占优 | 常识把"实力/技巧"等同优势；作者：优势也可能是弱势 |
| 混合动机博弈 / 讨价还价博弈 (mixed-motive / bargaining game) | 冲突关系与互存关系混合的非零和博弈；谢林用以统称战争、罢工、谈判 | 常识把博弈简单二分零和/非零和；作者强调"关系"而非仅"选择"的混合 |
| 聚焦点 (focal point) | 缺沟通时双方凭显著/唯一/惯例/对称不约而同锁定的解或暗示 | 常识以为逻辑最优；作者：往往是审美、对称、先例、传统等"非理性"暗示 |
| 默式谈判 (tacit bargaining) | 沟通不完全或无效下的谈判，靠行为、暗示、默契协调，而非语言 | 常识以为谈判必须"谈"；作者：许多谈判是沉默的行为博弈 |
| 战略行为 (strategic behavior) | 一方**影响对方对自己行为的预期**、从而约束对方决策的行为；先约束自己再约束对方 | 常识把策略视作"算计对方"；作者：先约束自己才能约束对方 |
| 威胁 (threat) | 第二步骤、以对方行为为前提条件、"伤你比我深"；失败时才付出代价 | 常识以"谁先动手"理解威胁；作者以"前提条件与代价归属"定义 |
| 允诺 / 承诺 (promise / commitment) | 第一步骤、单方面的自我约束；成功时才付出代价 | 常识把承诺与威胁混为一谈；作者：方向、代价归属均相反 |
| 随机性承诺 / 边际威胁 (randomized / fractional commitment) | 不承诺"一定"而承诺"以概率 p 做"，用随机化降低威胁成本、维持可信 | 常识以为威胁要斩钉截铁；作者：犹豫不决的威胁有时更优 |
| 边缘政策 (brinkmanship) | 人为制造自己也无法控制的失控风险，以可能同归于尽逼迫对方退让 | 常识把"边缘"想成可站稳的悬崖；作者：是带斜面的滑坡，越近越危险 |
| 意外战争威胁 (accidental war threat) | 风险来自己方掌控之外（偶然/机械失误/第三方），使"可能打"最可信 | 常识以为威慑靠意志；作者：靠"不可控"才最可信 |
| 突袭 / 相互威慑 (surprise attack / mutual deterrence) | 双方报复力量都可能被先发制人摧毁；稳定来自"谁先动手都无法消灭对方报复力" | 常识以"谁拳头硬"理解威慑；作者：以"无法被一击摧毁"理解 |
| 恐怖平衡 (balance of terror) | 类同古代人质交换的现代版：双方都把国民作人质，谁也无法偷袭对方反击能力 | 常识以"核武器数量"理解；作者：以"互相抵押人质"的心理结构理解 |
| 协调预期 (coordination of expectations) | 双方对彼此行为预期的相互对齐，是默式/显式谈判共通的心理机制 | 常识视为"达成共识"；作者：强调预期如何被暗示而非论证对齐 |
