# 冲突结构诊断：把对抗重述为可谈判博弈

## R — 原文 (Reading)

> "完全冲突通常只会在大规模毁灭性战争中出现……冲突中的'胜利'只能通过讨价还价、互谅以及避免采取互损行为得以实现。"
>
> — 托马斯·谢林, 《冲突的战略》 第 1、4 章

## I — 方法论骨架 (Interpretation)

大多数冲突（战争、罢工、价格战、堵车、家庭管教）不是零和，而是**混合动机博弈 / 讨价还价博弈**——冲突关系与互存关系混合。第一步是把对抗重述为可谈判的博弈：

① 判断三类结构：**完全冲突**（罕见，纯零和）、**完全合作**、**混合动机**（绝大多数现实冲突）；
② 找双方的共同利益与相互依赖（哪怕只是"避免两败俱伤"）；
③ 把"赢"重述为"找到双赢结果"——对抗中也有默契与协作空间。

这是一切应用（承诺、焦点、威慑）的入口：不先诊断结构，就容易把非零和当零和、把谈判当征服。

## A1 — 书中的应用 (Past Application)

### 案例 1: 两辆卡车狭路相逢
- 问题: 谁让路？
- 方法: 重述为讨价还价——双方都怕撞车（共同利益），"撞车"是双方惟一的威慑手段。
- 结果: "行动和语言一样能产生威慑"，威慑亦可表现为能力的丧失（第 1 章）。

### 案例 2: 成功罢工不是搞垮雇主
- 问题: 罢工如何算成功？
- 方法: 重述为混合动机——雇主也怕资不抵债，双赢才是目标。
- 结果: 战争同理，有限战争靠共同利益维持（第 1 章）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 陷入"你死我活"的对立叙事，想找出口
2. 谈判/纠纷/竞争中想先看清"这到底是零和还是可谈"
3. 想说服对方"我们有共同利益"
4. 设计制度/协议前想先定冲突结构

### 语言信号
- "这到底能不能谈 / 是不是零和"
- "怎么把对抗变成合作"
- "我们其实有共同利益吧"
- "is this zero-sum / reframe conflict as bargaining"

### 与相邻 skill 的区分
- 与 `focal-point`：本卡是"先诊断"；焦点是"诊断后无沟通如何协调"。
- 与 `credible-commitment`：本卡是前提，承诺是具体手段。

## E — 可执行步骤 (Execution)

**输入契约**：冲突各方、各自表面诉求、是否存在共同依赖（不合作则双输的点）。
**输出契约**：一个结构判定（完全冲突/完全合作/混合动机）+ 共同利益清单。

1. **问"不合作会怎样"**：若双方都硬扛会双输，则大概率是混合动机。
   - 完成标准: 找到"互损"的共同风险。
2. **找共同利益**：有限战争要有限、罢工要双赢、堵车要都别撞——列出 1–3 条。
   - 完成标准: 明确彼此都想要的结果。
3. **重述"赢"**：把"击败对方"改写为"找到双赢结果"。
   - 完成标准: 给出可谈判的目标表述。
4. **选工具**：无沟通靠 `focal-point`；要可信姿态靠 `credible-commitment`；要威慑靠 `threat-vs-promise`。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 真正的完全冲突（大规模毁灭性战争）——重述无意义，约束自己反被吞。
- 对方根本无谈判意愿、且你无施压手段时。

### 作者在书中警告的失败模式
- 把非零和当零和：忽略共同利益，错失协作空间。

### 作者的盲点
- 模型以国家行为体为主，对日常个人/商业迁移仅点到。

### 易混淆的邻近方法论
- `focal-point`、`credible-commitment`、`strategic-behavior` 都建于此诊断之上。
