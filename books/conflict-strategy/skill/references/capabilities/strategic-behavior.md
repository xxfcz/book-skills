# 战略行为：先约束自己，再约束对方

## R — 原文 (Reading)

> "战略行为是指，一方以对自己有利的方式影响对方对自我行为的预期判断……在限制对方行为之前必须首先限制自己的行为。"
>
> — 托马斯·谢林, 《冲突的战略》 第 5 章

## I — 方法论骨架 (Interpretation)

战略行为是一套统一心法：你无法直接命令对方，只能**影响对方对你行为的预期**，进而让对方自愿做出对你有利的选择。核心次序反直觉——**在限制对方之前，必须先限制自己**。

操作骨架：
① 给自己建立一个可被对方观察到的、稳定的行为模式；
② 把你的处境"传达"给对方一个**最大化问题**（让对方在你设定的框架里算自己的最优解）；
③ 通过子机制实现：授权（移交决策权给更坚决者）、沟通及其破坏性（有时切断沟通是优势）、主动放弃主动权、引入调停者。

这一心法贯穿承诺、焦点、威慑——它是下游所有具体手段的"元层"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 坎农投燃烧汽油桶（放弃主动权）
- 问题: 飞行员如何不靠下令就让地面部队退让？
- 方法: 放弃"是否报复"的主动权，把燃烧桶投向地面部队——无需威胁，机制本身即成势（第 5 章，c07）。
- 结果: "行动和语言一样能产生威慑"。

### 案例 2: 工会人为缩小权限（授权）
- 问题: 谈判代表如何让管理层相信其强硬底线？
- 方法: 说服工人"管理部门能接受 2 美元否则无能"，使自身看似无法控制工人、放弃阻止罢工的权力（第 2 章，c03）。
- 结果: 看似让权，实则把底线坐实。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 想影响对手/伙伴决策，却无法直接命令或控制对方
2. 谈判/博弈中想"设一个框架让对方自己选对我有利的项"
3. 管理/授权中想用"交出权力"反增控制力
4. 想理解"为什么切断沟通有时反而是优势"

### 语言信号
- "怎么影响对方的判断 / 让他自己选对我有利的"
- "怎么设个局让对方进退都对我好"
- "授权/交出权力反而更强"
- "strategic behavior / framing the other's choice / commitment as strategy"

### 与相邻 skill 的区分
- 与 `credible-commitment`：本卡是统一心法；后者是"约束自己"的具体机制。
- 与 `threat-vs-promise` / `focal-point`：本卡提供框架，它们提供具体方向/方法。

## E — 可执行步骤 (Execution)

**输入契约**：你想让对方做的选择、你有哪些可被观察的行为、你能否改变"对方眼中的你的选择集"。
**输出契约**：一套"行为模式＋最大化问题"设计，使对方在自利下选你期望项。

1. **确立目标选择**：明确你希望对方最终采取的那一项。
   - 完成标准: 目标可表述为对方的一个具体动作。
2. **建可观察的行为模式**：让对方稳定地"看到"你的立场/限制（公开、一贯、不可退回）。
   - 完成标准: 对方无需额外验证即能感知。
3. **把处境转成对方的最大化问题**：调整选项结构，使其在自利计算下落到你期望项。
   - 完成标准: 对方"为自己好"就会选你想要的。
4. **选子机制**：授权给更坚决者 / 放弃主动权 / 切断有害沟通 / 引入调停者。
   - 判停: 若调整后反而削弱可信度，回退到 `credible-commitment` 补约束。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 对方完全无视你的信号、或你无力建立可观察行为时。
- 你设的"最大化问题"在对方真实收益下反而导向不利项（框架错）。

### 作者在书中警告的失败模式
- 只靠言语不靠事实（x06）：枪要上膛可见、契约要不可逆，否则对方不信。
- 误以为"更多相机权＝更有利"（x02）：保留所有退路反而削弱战略姿态。

### 作者的盲点 / 时代局限
- 以国家行为体为主，对日常个人/商业迁移仅点到。

### 易混淆的邻近方法论
- `credible-commitment`（约束机制）、`threat-vs-promise`（方向）、`bargaining-game`（诊断入口）。
