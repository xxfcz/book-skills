# 聚焦点：在僵局中找"显著解"

## R — 原文 (Reading)

> "能否找到问题的最佳解决方法, 很大程度上取决于双方的直觉而非逻辑……对称性、审美观或几何原理。"
>
> — 托马斯·谢林, 《冲突的战略》 第 3 章

## I — 方法论骨架 (Interpretation)

当双方无法或不愿显式沟通时，靠**显著性、唯一性、惯例、对称、先例**等暗示，可以不约而同锁定一个解（聚焦点），达成默契——这叫默式谈判（tacit bargaining）。

三步：
① 识别双方共享经验/文化/地理；
② 找"最醒目 / 最对称 / 最惯例"的那个点（而非逻辑最优）；
③ 把它当作双方共同的焦点。

经典证据：百货商场走散的夫妇多奔向服务台；空降兵奔向地图中"唯一显著的标志"；三八线、禁毒气是战争中的默契焦点。

## A1 — 书中的应用 (Past Application)

### 案例 1: 百货商场走散的夫妇（问卷实验）
- 问题: 未约地点如何重逢？
- 方法: 双方都奔向"最醒目的地点"（服务台/圆形中心/十字路口）。
- 结果: 问卷证明人们靠直觉协调预期，成功率远高于随机（第 3 章）。

### 案例 2: 三八线与禁毒气（有限战争）
- 问题: 战争如何保持"有限"？
- 方法: 三八线（清晰天然界线）锁住对峙；"完全禁止毒气"因最易成惟一合作点而被默契遵守。
- 结果: 朝鲜战争有限性、二战无毒气战皆源于焦点默契。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 谈判僵局、双方都不愿先让步
2. 无沟通/弱沟通下要达成默契（分工、分界线、默认规则）
3. 想找"自然的折中/整数/惯例"破局
4. 组织/双边关系缺显式协议却有默认秩序

### 语言信号
- "怎么打破僵局 / 谁先让一步"
- "没有沟通怎么达成一致"
- "有没有自然的分界线/惯例可用"
- "focal point / tacit bargaining / coordination without talking"

### 与相邻 skill 的区分
- 与 `bargaining-game`：本卡是"无沟通时如何协调"；后者是"先诊断冲突结构"。
- 与 `credible-commitment`：焦点靠暗示，承诺靠约束。

## E — 可执行步骤 (Execution)

**输入契约**：僵局/无沟通场景、双方共享的语境（地理、文化、先例、对称物）。
**输出契约**：一个"显著点"建议 + 为何双方都会选它。

1. **找共享语境**：双方都看得见/都认可的显著性、唯一性、对称、先例是什么？
   - 完成标准: 列出 2–3 个候选暗示。
2. **挑最"醒目"的那个**：越唯一、越对称、越有惯例，越易被双方共同选中。
   - 完成标准: 选定一个并说明其显著性来源。
3. **用整数/折中/天然界线落地**：价格用整数、争议用折中、边界用河/纬线。
   - 完成标准: 给出一个可执行的焦点。
4. **检验对方是否同解**：若对方可能选不同点，补显式沟通或引入调停者。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 双方毫无共享语境、显著点完全不对称时（如陌生地形无标志）。
- 焦点本身不稳定（如配额制可被渐进侵蚀）。

### 作者在书中警告的失败模式
- 小步让步会塌方："仅一点而已"导致一再退让（焦点具"不易妥协"的动态特征）。
- 焦点依赖惯例，但惯例可被打破（如 5-5 分成在歧视性机制下失效）。

### 作者的盲点
- "是什么因素决定答案"作者坦承无法科学证明，属经验性。

### 易混淆的邻近方法论
- `bargaining-game`（诊断结构）、`strategic-behavior`（主动操纵预期）。
