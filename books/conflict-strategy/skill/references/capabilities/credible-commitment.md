# 可信承诺：用自我约束换取谈判力

## R — 原文 (Reading)

> "遏制对手的权力就是限制自己的权力。……破釜沉舟也许意味着给对方更多的机会。"
>
> — 托马斯·谢林, 《冲突的战略》 第 1–2 章（序言以"炸毁唯一逃生桥"为范例）

## I — 方法论骨架 (Interpretation)

在谈判、威慑、组织中，一方以**可信且可观察**的方式限制自己的某些选择自由，会改变对方对自己行为的预期，从而增强自身地位。这与常识相反：常识认为"保留更多退路=更有利"，谢林指出保留退路＝威胁/承诺不可信＝地位下降。

四条可操作的自我约束路径：
① **不可逆契约/自动反应**：签不能反悔的协议、把"是否报复"交给预设机制；
② **公开实盘**：一旦发盘即绑定，让对方知道"这是最终价"；
③ **授权给更坚决的第三方**：把决策权交给意志更强、或被迫无法妥协的对象；
④ **放弃主动权**：主动把"是否行动"交给对方或不可控过程。

核心判据：**只有对方相信你"真的无法回头"，你的姿态才可信。**

## A1 — 书中的应用 (Past Application)

### 案例 1: 炸桥（可信承诺母案例）
- 问题: 如何让敌人相信你誓死不退？
- 方法: 炸毁唯一逃生桥 —— 限制自身行动空间，吓退敌人。
- 结果: 谢林称其为"置于死地而后生"最佳例证（序言）。

### 案例 2: 买方受第三方契约约束（不可更改报价）
- 问题: 买方如何把谈判空间锁死在 16000 内？
- 方法: 与第三方签不可反悔协议——出价超 16000 即输 5000。
- 结果: 卖方知事实后，谈判空间被主动、明确、完全逆转（第 2 章）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 谈判/还价中想让对方相信自己的底线或威胁是认真的
2. 管理/合作中想用"交出去的权力"增强承诺可信度
3. 威慑/博弈中想让威胁生效却苦于"对方不信你会动手"
4. 想约束未来的自己（如戒烟、守预算、不临时妥协）

### 语言信号
- "怎么让他相信我是认真的 / 我的威胁不是空话"
- "怎么增强承诺的可信度 / 让协议有约束力"
- "我留了后路反而谈不拢"
- "how to make a threat credible / commit credibly / burn the bridge"

### 与相邻 skill 的区分
- 与 `strategic-behavior`：本卡是"约束自己"的具体机制；strategic-behavior 是统一心法。
- 与 `threat-vs-promise`：本卡讲"让承诺可信"；后者讲"该用威胁还是允诺"。

## E — 可执行步骤 (Execution)

**输入契约**：需明确——你想让对方相信什么（底线/威胁/允诺）、你有哪些"可观察"的约束手段、对方是否知情。
**输出契约**：一张"约束手段清单"＋对方可观察的证据。

1. **判定你要的可信度类型**：是"不可更改的承诺"(第一步骤) 还是"可信的威胁"(第二步骤)？
   - 完成标准: 明确归类，否则先读 `threat-vs-promise`。
2. **选一条不可逆手段**：契约/自动机制/授权/放弃主动权。
   - 完成标准: 该手段在对方视角"真的无法回头"（如契约有第三方强制、授权对象无权妥协）。
3. **让约束"可观察"**：把证据交给对方（寄到的支票、上膛可见的枪、公开的普遍性原则）。
   - 完成标准: 对方无需额外验证即可相信。
4. **避免反噬**：确认约束不会被对方反制或逼你两败俱伤。
   - 判停: 若约束会导致你被轻易勒索，回退到 `strategic-behavior` 重估。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- 零和、纯对抗、毫无共同利益的极端冲突——约束自己无意义。
- 约束是**被迫**的（弱者的自我伤害）或会被对方直接反制时。

### 作者在书中警告的失败模式
- "更多相机决策权反而损害利益"：保留所有退路＝不可信（x02）。
- 只靠言语不靠事实："枪已上膛"若无可观察行动，没人信（x06）。

### 作者的盲点 / 时代局限
- 案例高度国家/冷战化；对商业、个人迁移只点到为止。
- "显著点/惯例能协调预期"来自问卷与直觉，作者坦承无法严格证明。

### 易混淆的邻近方法论
- `threat-vs-promise`（方向选择）、`strategic-behavior`（统一心法）、`randomized-commitment`（用随机化替代全有全无）。
