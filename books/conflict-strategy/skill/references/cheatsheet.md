# 决策规则速查 — 《冲突的战略》(The Strategy of Conflict)

| 能力 | 一句话规则 |
|---|---|
| 冲突结构诊断：把对抗重述为可谈判博弈 | 先判断完全冲突/完全合作/混合动机，再找共同利益，把"赢"重述为"双赢"。 |
| 可信承诺：用自我约束换取谈判力 | 以可观察、不可逆的方式限制自己的选择自由，改变对方预期，反而增强地位。 |
| 威胁 vs 允诺的结构化选择 | 阻止前进用威慑（自断后路），迫使让步用威胁（显示决死）——方向先选对。 |
| 聚焦点：默式谈判找"显著解" | 无法显式沟通时，靠显著性/对称/惯例/先例不约而同锁定一个解。 |
| 战略行为：先约束自己，再约束对方 | 影响对方对你行为的预期，再让其自愿选对你有利的项；次序是"先约束自己"。 |
| 随机化承诺：用"概率化威胁"降低可信成本 | 不承诺"一定"做，而承诺"以概率 p 做"，用随机化在双方间分配过大威胁。 |
| 边缘政策：制造"自己也无法收回"的失控风险 | 人为制造自己也无法控制的失控风险，以"可能同归于尽"逼对方退让。 |
| 消除突袭恐惧：建立稳定的相互威慑 | 让"无论谁先动手都无法消灭对方报复力"成事实，并消除先发制人动机。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
